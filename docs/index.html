PORTFOLIO CASE STUDY

Kridh Capital

A private market-analytics and paper-trading project, presented through an independent public interface demo.

The product problem

Research, portfolio state and trade records are often fragmented. A unified workspace makes candidates easier to review, exposure easier to inspect and decisions easier to trace.

My contribution

The original personal project includes Python-based data processing, analytics, paper-trading workflows and reporting. This public demo showcases product workflow and interface design with independently written HTML, CSS and JavaScript.

Public demo architecture

Synthetic fixtures→Browser state→Charts & tables→Demo CSV exports

What you can verify here

  • Search and sector/status filtering.
  • Deterministic chart periods and computed allocation.
  • Paper-buy validation and consistent cash/position updates.
  • Session-only journal and CSV exports.
  • Responsive, keyboard-accessible dashboard screens.
